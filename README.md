# Управленческие отчеты (RM-MR)

Интерактивная дорожная карта контура управленческих отчетов ЭНКО.

**RM-MR** = Road map Management Report.

Сайт показывает этапы OVKS **0–6**: календарь, Gate, параллельные треки **паллиатив** и **фундаментал**. Это не выгрузка wiki. Цифры, маппинг счетов, суммы и служебные секреты в репозиторий не входят.

Фирменный стиль — с [brand.enco72.ru](https://brand.enco72.ru/): синий `#122A4B`, серый `#758795`, золотой `#CFC393`, шрифт Montserrat, знак ЭНКО.

## Открыть

- GitHub Pages: https://enco-it.github.io/RM-MR/
- Локально: открыть `docs/index.html` или любой static server из каталога `docs/`

Публикация Pages: ветка **`main`**, каталог **`/docs`**. Файл `docs/.nojekyll` отключает обработку Jekyll.

## Состав

| Путь | Назначение |
| --- | --- |
| `docs/index.html` | Карта, принципы, системы, техдолг, риски |
| `docs/assets/` | Favicon и знак ЭНКО с бренд-сайта |
| `docs/.nojekyll` | GitHub Pages без Jekyll |

Источник постановки — пространство OVKS, страница «Управленческие отчеты» и дочерние этапы 1–4. Этапы 0, 5 и 6 на родителе.

## Не коммитить

Токены, `confluence.env`, дампы wiki, бюджетные суммы, таблицы маппинга счетов.
